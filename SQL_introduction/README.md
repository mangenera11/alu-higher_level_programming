# SQL - Introduction

This project covers the basics of working with a MySQL database.

## Files

- `0-list_databases.sql`: script that lists all databases of the MySQL server.
- `1-create_database_if_missing.sql`: script that creates the database `hbtn_0c_0` in the MySQL server if it doesn't exist.
- `2-remove_database.sql`: script that deletes the database `hbtn_0c_0` in the MySQL server if it exists.
