# python-everything_is_object

This project covers the basics of how Python treats everything as an object.

## Topics
- Objects, types, and identity
- Using `type()` and `id()`
- Mutable vs immutable objects
- How Python passes arguments to functions

## Tasks
- `0-answer.txt`: function used to print the type of an object
- `1-answer.txt`: function used to get a variable's identifier (memory address in CPython)
