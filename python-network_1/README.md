# python-network_1

Python scripts that make HTTP requests using the `urllib` and `requests`
packages.

## Files

- `0-hbtn_status.py`: fetches a status page with `urllib`
- `1-hbtn_header.py`: displays the `X-Request-Id` response header with `urllib`
- `2-post_email.py`: sends a POST request with an email using `urllib`
- `3-error_code.py`: displays the response body or the HTTP error code with `urllib`
- `4-hbtn_status.py`: fetches a status page with `requests`
- `5-hbtn_header.py`: displays the `X-Request-Id` response header with `requests`
- `6-post_email.py`: sends a POST request with an email using `requests`
- `7-error_code.py`: displays the response body or the error code with `requests`
- `8-json_api.py`: sends a letter to a search API and displays the JSON result
- `10-my_github.py`: displays your GitHub id using Basic Authentication

## Usage

Make a script executable and run it:

    chmod u+x 0-hbtn_status.py
    ./0-hbtn_status.py
