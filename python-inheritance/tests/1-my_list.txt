Test cases for the MyList class
===============================

>>> MyList = __import__('1-my_list').MyList

Empty list:

>>> my_list = MyList()
>>> my_list.print_sorted()
[]

Unsorted list:

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(4)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> my_list.print_sorted()
[1, 2, 3, 4, 5]

Original list is not modified:

>>> print(my_list)
[1, 4, 2, 3, 5]

Negative numbers and duplicates:

>>> my_list = MyList([3, -1, 2, 3, -5])
>>> my_list.print_sorted()
[-5, -1, 2, 3, 3]

Already sorted:

>>> my_list = MyList([1, 2, 3])
>>> my_list.print_sorted()
[1, 2, 3]

MyList is a list:

>>> isinstance(my_list, list)
True
>>> issubclass(MyList, list)
True
