# Python - Inheritance

This project covers inheritance and introspection in Python.

## Files

- `0-lookup.py`: returns the attributes and methods of an object.
- `1-my_list.py`: `MyList` class that inherits from `list`.
- `2-is_same_class.py`: checks for an exact instance of a class.
- `3-is_kind_of_class.py`: checks for an instance or subclass instance.
- `4-inherits_from.py`: checks for a strict subclass instance.
- `5-base_geometry.py`: empty `BaseGeometry` class.
- `6-base_geometry.py`: adds `area()` that raises an exception.
- `7-base_geometry.py`: adds `integer_validator()`.
